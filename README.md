## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Session Manager** | Save and resume Disk Drill recovery scan sessions |
| **File Filter** | Filter found files by type, size and modification date |
| **Recovery Log** | Track recovered files with source path and output destination |
| **Vault Manager** | Manage Recovery Vault protection rules per drive |
